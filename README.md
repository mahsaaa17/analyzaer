# Grounded Theory Qualitative Analyzer

سامانه ماژولار و مکانیزه تحلیل کیفی داده‌های پژوهش (بر اساس رویکرد نظریه داده‌بنیاد اشتراوس و کوربین)

## ساختار پروژه
- `src/data_processor.py`: وظیفه بارگذاری و استخراج داده‌ها از فایل‌های ورد و اکسل را دارد.
- `src/excel_generator.py`: ساخت و خروجی اکسل تحلیل به صورت راست‌چین و قالب‌بندی شده.
- `requirements.txt`: نیازمندی‌های کتابخانه‌ای پروژه.

## روش اجرا روی سرور یا لوکال
1. ابتدا پیش‌نیازها را نصب کنید:
   ```bash
   pip install -r requirements.txt
   ```
2. پروژه را اجرا کنید.
